# AIML Game

Run the game with:

```powershell
python .\ai_arithmetic_maze_race_2.py
```

The game now uses a Decision Tree Classifier to predict player skill from score, accuracy, and response time, then adapts the next round's difficulty.

AI A* Maze Race
----------------

Run the Player-vs-AI A* demo with:

```powershell
python .\ai_arithmetic_maze_race_2.py
```

This single-file demo visualizes the A* search algorithm (open/closed sets,
heuristic f(n)=g(n)+h(n)) and shows both the human player and AI moving in
real time toward the goal.
